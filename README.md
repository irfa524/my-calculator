# Modern Calculator

A simple calculator web app built with HTML, CSS and JavaScript.

**Live demo:** https://my-calculator-cum2.vercel.app

## Features
- Addition, subtraction, multiplication and division
- Decimal numbers
- Clear (C) and backspace (⇐) buttons

## Run locally
Download the files and open `index.html` in your browser.

## Built with
HTML, CSS, JavaScript. Deployed on Vercel.
